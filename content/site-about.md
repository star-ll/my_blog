## 你好，我是余烬

我是一名以前端工程为基础的软件工程师，现在也在深入学习 Rust，探索 AI Agent 与 AI Coding 的工程实践。

我喜欢追问一个系统为什么这样工作，再通过代码验证自己的理解。这个网站记录我的技术文章、实验项目，以及仍在形成中的思考。

## 我的技术底色

前端是我积累最久的领域。我做过金融 ToB 系统，也参与过面向用户的 H5 产品开发，接触过微前端、动态表单、性能优化和复杂交互等工程问题。

除了交付功能，我也关注浏览器、JavaScript 运行时和框架内部机制。博客中的浏览器引擎、垃圾回收、React 原理和系统设计文章，就是这些探索的记录。

## 通过构建理解原理

我曾实现过 [[site-deco\|Deco]]：一个借鉴 Vue 原理的 Web Components 框架。

如今我更看重它作为学习与教学实验的价值。亲手连接响应式、渲染、调度和组件模型，让我更具体地理解框架设计中的边界与权衡。

我也在用 Rust 构建轻量 Agent，在推进项目的同时学习这门语言。当前关注工具调用、会话、上下文和编排，希望逐步把它们组织成一个简单、可靠、能够持续演进的系统。

## 我关心的 AI 工程问题

模型能生成代码、调用工具之后，怎样让整个系统更稳定？

我尤其关注工程约束和反馈机制：如何组织上下文，如何发现执行中的问题，以及如何让审查、测试与人的反馈影响下一次执行。

围绕 AI Coding Harness 的实践，也让我越来越重视一个问题：当生成变得容易，如何验证结果、积累经验，并减少相同错误的重复发生？

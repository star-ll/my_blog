## 你好，我是余烬

一名从前端走向 AI 应用与系统工程的软件工程师。做过金融 ToB 系统和 C 端 H5 产品，喜欢把复杂问题拆清楚，也愿意深入原理，把系统做扎实。

**TypeScript · Vue / React · Node.js · Rust · AI Agent**

前端是我的技术底色：从微前端、动态表单到性能优化与内存泄漏排查，既关注功能交付，也关注系统的结构和运行机制。我还写过 [Deco](site-deco.md)，一个借鉴 Vue 原理实现的 Web Components 框架，用来探索框架设计与工程权衡。

现在，我把更多精力放在 Agent 和 AI Coding 上：用 Rust 构建轻量 Agent，实践上下文管理、工具调用与执行编排；围绕 Harness 探索如何用工程约束和反馈机制，让 AI 编码更可靠。

我希望参与前端、全栈或 AI Agent 相关的工程工作，把已有的前端经验与正在深入的 AI 系统能力结合起来。

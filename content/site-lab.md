我习惯通过构建一个能够运行的系统，检验自己是否真正理解了它。

## Deco · 框架设计实验

一个借鉴 Vue 设计原理、基于 Web Components 实现的前端框架。

现在，我更关注它的教学价值：通过一个可阅读、可运行的实现，讨论响应式、渲染、调度与组件设计之间的关系和取舍。

- [[site-deco\|了解 Deco 的设计与定位]]
- [查看源码](https://github.com/star-ll/Deco)

## Rust Agent · 进行中的探索

用 Rust 构建轻量的个人 Agent，在实践中学习工具调用、会话管理、上下文组织与执行编排。

目标是逐步形成一个可理解、可观察、受工程约束的系统，而不只是让模型完成一次工具调用。

## AI Coding Harness · 工程实践

围绕规则、Skills、代码审查与反馈机制，探索如何让 AI 编码的结果更稳定、更容易维护。

我尤其关注反馈如何回到下一次执行中：发现问题、记录证据、调整约束，再验证是否有效。

## Featured

### [[lab/deco|Deco]]

一个借鉴现代前端框架设计思想、基于 Web Components 实现的教学型框架。它不是为了与成熟框架竞争，而是用一个完整实现讨论响应式、渲染、调度、生命周期和 API 设计之间的权衡。

- TypeScript
- Reactive System / JSX Renderer / Scheduler
- Decorators / Lifecycle / State Management / Plugins
- Playwright tests
- [Source](https://github.com/star-ll/Deco)

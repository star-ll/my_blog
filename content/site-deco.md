## 为什么构建 Deco

Deco 是我借鉴 Vue 原理实现的 Web Components 框架。构建它的过程，让我有机会把阅读源码时接触的概念，重新放进一个自己能够理解和调整的系统里。

它的定位已经从“希望有人使用的前端框架”，转向“具有教学价值的框架设计实验”。

## 我想通过它理解什么

- 状态变化如何被追踪，并触发界面更新？
- 响应式、渲染与调度之间如何分工？
- 多次更新如何合并，更新时机如何选择？
- Web Components 的生命周期如何与框架的组件模型配合？
- API 应该隐藏哪些复杂度，又保留哪些控制能力？

## 教学价值

Deco 让我把响应式、渲染、调度和组件模型放在一起理解，而不是只记住各自独立的概念。

我希望读者既能看到一个选择如何实现，也能知道为什么这样选择，以及它带来了什么限制。
